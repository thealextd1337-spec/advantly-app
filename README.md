# advantly-app

Öffentlicher Spiegel des App-Codes von [Advantly](https://advantly.eu) (Kotlin Multiplatform: Android, Wear OS, iOS,
watchOS). Er existiert nur für die macOS-CI (Kotlin/Native-Tests, iOS-/watchOS-Simulator-Builds).

Der Inhalt wird automatisch aus dem internen Repository überschrieben, jeder Stand ist ein einzelner Commit ohne
Historie. Änderungen und Pull Requests hier gehen verloren.
